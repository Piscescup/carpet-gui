# Workspace PNG icons

Generated with the built-in `image_gen` tool, with `transparent_background: true`. These are original grayscale pixel-style assets; no BetterStats artwork was used as input or copied.

Final assets: `src/main/resources/assets/carpet-gui/textures/gui/icons/`. The GUI displays each icon at 20 × 20 logical pixels. Generated PNGs retain their original resolution and alpha channel.
